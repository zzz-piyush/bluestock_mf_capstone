# Mutual Fund Analytics Platform — Data Dictionary

## 1. dim_fund

Master table containing mutual fund scheme information.

| Column | Description |
|---|---|
| amfi_code | Unique AMFI scheme code |
| fund_house | Mutual fund company |
| scheme_name | Name of the mutual fund scheme |
| category | Fund category |
| sub_category | Fund sub-category |
| plan | Fund plan type |
| launch_date | Scheme launch date |
| benchmark | Benchmark index |
| expense_ratio_pct | Expense ratio in percentage |
| exit_load_pct | Exit load in percentage |
| min_sip_amount | Minimum SIP investment amount |
| min_lumpsum_amount | Minimum lumpsum investment amount |
| fund_manager | Fund manager |
| risk_category | Risk classification |
| sebi_category_code | SEBI category code |

**Primary Key:** `amfi_code`

---

## 2. dim_date

Date dimension used for time-based analysis.

| Column | Description |
|---|---|
| date | Calendar date |
| year | Year extracted from date |
| month | Month number |
| month_name | Month name |
| quarter | Financial/calendar quarter |

**Primary Key:** `date`

---

## 3. fact_nav

Historical Net Asset Value (NAV) of mutual fund schemes.

| Column | Description |
|---|---|
| amfi_code | AMFI scheme code |
| date | NAV date |
| nav | Net Asset Value |

**Primary Key:** `amfi_code, date`

**Foreign Keys:**
- `amfi_code → dim_fund.amfi_code`
- `date → dim_date.date`

---

# Data Quality Rules

## NAV History

- Dates converted to proper date format.
- Records sorted by AMFI code and date.
- Duplicate fund-date records checked.
- Missing NAV values handled using forward filling.
- NAV values must be greater than zero.

## Investor Transactions

- Transaction types standardized to:
  - SIP
  - Lumpsum
  - Redemption
- Transaction amounts must be greater than zero.
- Transaction dates validated.
- KYC status standardized.

## Scheme Performance

- Performance metrics converted to numeric values.
- Missing numeric values checked.
- Expense ratio validated against the expected range of 0.1%–2.5%.
- Performance anomalies checked without arbitrarily deleting valid records.
